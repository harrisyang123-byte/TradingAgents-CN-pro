# 超级投资人衡量标尺库（真执行 vs 浅尝即止）

> **用途**：自进化优化循环（`planning/v4/self-evolving-optimization-loop.md`）的"探照灯"+"深度闸门"。
> **核心问题**：每条超级投资人实践，我们是**真做到了**，还是只是**嘴上引用**？差距最大的那条 = 当前最痛的洞。

## 谁必须用这把尺

| Agent | 用法 |
|---|---|
| `v4-chief-investment-officer` | DISCOVER 阶段：逐条扫描系统产物，找"嘴上有、流程无"的洞，按伤害排序锁定 1 个 |
| `v4-investor-critic` | GATE 阶段：用 §2 深度闸门 rubric 给"改后产物"打分，<85 退回重做 |
| 任何 director | 自检：我这份 verdict 真用了哪条超级投资人实践？还是只是名字好看？ |

## §1 标尺库（真执行 vs 浅尝即止对照）

### 巴菲特 / 芒格
- **能力圈**：✅显式标认知边界、看不懂降confidence ｜ ❌什么都敢给目标价
- **护城河量化**：✅五力+卡位+ROIC>WACC量化宽度与趋势(变宽/变窄) ｜ ❌一句"有护城河"完事
- **安全边际**：✅买点=内在价值×(1−margin)且内在价值有推导链 ｜ ❌买点拍脑袋无锚
- **逆向思考**：✅先建死亡清单(怎么亏光)再反推 ｜ ❌只论证看多
- **股东盈余/FCF**：✅用FCF剔维持capex ｜ ❌只看PE/净利润
- **多元思维格栅**：✅跨学科交叉验证 ｜ ❌只用财务单维

### 段永平
- **商业模式优先**：✅先问是不是好生意(现金流/复购/定价权)再谈价 ｜ ❌只看便宜
- **Stop doing list**：✅显式维护"不做什么" ｜ ❌什么都想抓
- **管理层资本配置**：✅评估分红/回购/并购质量 ｜ ❌不看人
- **做对的事+把事做对**：✅查方向对不对 AND 执行深不深 ｜ ❌方向对就以为完了

### 霍华德·马克斯 / Serenity
- **二阶思维/预期差**：✅问市场price-in了什么、我和共识差异在哪 ｜ ❌跟共识
- **周期定位**：✅判渗透率S曲线/库存/估值分位 ｜ ❌线性外推
- **风险=永久损失本金**：✅区分波动vs永久损失,防后者 ｜ ❌用beta当风险
- **无人知晓的瓶颈(紫苏叶)**：✅上溯产业链碎片演绎找低关注卡位 ｜ ❌只买已知龙头/研报验证

### 达里奥
- **原则化+极度求真**：✅每判断可证伪+留痕+复盘 ｜ ❌拍脑袋不留痕
- **What am I missing?**：✅主动找反面证据/盲区 ｜ ❌确认偏误
- **真分散**：✅按驱动因子分散 ｜ ❌堆同赛道假分散

### 费雪 / 李录 / 格雷厄姆
- **闲聊法scuttlebutt**：✅客户名单/产能地图/专利碎片一手演绎 ｜ ❌只读研报
- **错杀龙头识别**：✅区分错杀卡位龙头vs双杀,不按PE分位一刀切 ｜ ❌分位高就排除
- **好公司×好价格×好未来**：✅三维同看 ｜ ❌只看便宜(陷阱)或只看成长(透支)

### 机构 IPS / SOP（Bridgewater / Yale / CFA / 顶级公募）— 流程锚
- **集中度上限**：✅单股≤X%/单行业≤Y%/top10≤Z%写进IPS可报警 ｜ ❌"不要太集中"无阈值
- **流动性约束**：✅days-to-liquidate(ADV20%)加权≤N天 ｜ ❌只看市值
- **再平衡触发**：✅偏离±X%或时间窗N月触发 ｜ ❌凭感觉调
- **卖出明文化**：✅建仓时同步写卖出条件(论点失效+价格阈值+时间止损) ｜ ❌只写买入
- **回顾制度化**：✅月度持仓review/季度归因/年度IPS复审留痕 ｜ ❌跑完就完
- **多PM委员会**：✅重大变动≥2独立PM签字(critic真spawn对应) ｜ ❌单点拍板
- **预算/容量约束**：✅alpha半衰期+容量上限,超容量降权 ｜ ❌信号好就无限放大
- **GIPS归因**：✅拆解alpha/beta/择时/选股/费用 ｜ ❌只看总收益

### 死亡清单（失败案例反向锚）— critic 必逆向自问
- **LTCM98相关性崩溃**：✅按驱动因子算相关+压测全相关 ｜ ❌堆数量假分散
- **Archegos21杠杆+集中+衍生品**：✅集中度+总杠杆+隐性敞口三道闸 ｜ ❌卡位龙头敢all-in
- **Woodford19流动性错配**：✅days-to-liquidate≤赎回窗×2 ｜ ❌只看市值
- **乐视/康美现金流vs净利背离**：✅OCF持续<净利+资本开支异常即红线 ｜ ❌只看PE/EPS
- **15杠杆牛崩盘**：✅估值分位+融资余额+开户三同高→系统减 ｜ ❌"还能再涨"
- **21核心资产抱团瓦解**：✅公募集中度+北向重叠+估值分位三超阈→警报 ｜ ❌"抱团=好股"
- **24高股息抱团**：✅看分红来源+股息覆盖率+行业景气 ｜ ❌"高股息=安全"
- **概念股一日游**：✅催化兑现度量化+盈利路径时间表 ｜ ❌跟风后说"市场不理性"
- **价值陷阱低PE**：✅必配ROIC趋势+现金流转正+终局市占,三不通即避 ｜ ❌看便宜就买

### 行业研究 SOP（晨星 / 卖方 initiation）— 工业标准模板
- **护城河5类来源(晨星)**：✅显式分类无形/转换/网络/成本/规模+wide/narrow/none+趋势 ｜ ❌"有护城河"完事
- **催化剂时间表**：✅每论点≥1个时间窗+量化阈值 ｜ ❌"未来会兑现"无时间
- **KPI监控面板**：✅列5-10指标+当前值+警报阈值 ｜ ❌写完不留监控
- **三情景估值**：✅Bull/Base/Bear+概率权重+假设差异,期望≥现价+安全边际 ｜ ❌只给一个base
- **风险下行情景**：✅基本面双杀/估值杀/政策杀具体路径+下行幅度 ｜ ❌"宏观/政策风险"放四海
- **可比论证**：✅≥3家可比+why comparable+加权目标PE ｜ ❌拍1个PE无依据
- **Initiation结构强制**：✅Thesis/Catalysts/Valuation/Risks/Monitoring缺一不达标 ｜ ❌自由发挥
- **拥挤度自查**：✅公募集中+北向重叠+卖空比→crowded/normal/contrarian ｜ ❌不查price-in

> 标尺库是活的：发现未收录的实践 → CONSOLIDATE 阶段补进本表。
> 三锚原则：思想锚(巴/段/马/达/费) + 流程锚(IPS) + 反向锚(死亡清单) + SOP锚(晨星/卖方)，缺一不可。

## §2 深度闸门 rubric（浅尝即止检测器）

### 浅尝即止 5 大特征（命中任一 = 浅，shallow_score +1）
1. 一句话定性零量化 2. 套话填字段(换个股也成立) 3. 断层不闭环(没落到买什么)
4. 拍脑袋数字(无verified+推导链) 5. 不可证伪(无反向信号)

### 深度达标 5 条（全满足才 ACCEPT）
1. **可量化**(数字+趋势+对比) 2. **可证伪**(配反向信号绝对阈值) 3. **闭环到行动**(落到买什么/买多少/什么价买卖)
4. **数据verified**(来源URL或标missing,禁编造) 5. **方法论显式**(用了§1≥1条且写出怎么用)

### GATE 打分卡（满分100，<85=NEEDS_CHANGES）
```
- 可量化       /20
- 可证伪       /20
- 闭环到行动   /20
- 数据verified /20
- 方法论显式   /20
浅尝特征命中：[1-5项]
判定：ACCEPT / NEEDS_CHANGES
回退反馈：[具体指出哪还浅、该怎么深]
```

## §2.6 pre-mortem 标准模板（巴菲特-逆向思考 + 死亡清单 + 达里奥-可证伪 三标尺合一）

> 三标尺合并为一个可落地字段。每只股票 director 必输出 `pre_mortem` 字段，三大死亡场景齐写，缺任一 critic 直接 NEEDS_CHANGES。这是把"防永久损失本金"从口号变成流程的核心。

### 三大死亡场景模板（必填三场景，不许"风险段一句话")
```json
"pre_mortem": {
  "fundamental_double_kill": {
    "scenario": "基本面双杀路径(含≥1 KPI 数字+具体业务因果链, 如'客户A 占比 32%, 若大客户 capex 同比 -40% 持续 2 季 → 毛利率 42%→25%'). 仅一句定性='客户砍单+毛利下滑' = 浅尝套话直接 NEEDS_CHANGES",
    "trigger_indicators": ["≥3 个绝对阈值, 必须含数字+方向词('扣非净利率<5%连续2季'/'存货周转<60天'). 禁相对偏离词('跌X%/下滑Y%/低于历史Z')"],
    "downside_pct": "-XX% 至 -YY%",
    "downside_price": "¥XX",
    "verified_anchor": {
      "trigger_observed_values": [{"indicator": "...", "current_value": "...", "verified_source": "URL/AKShare/财报"}],
      "downside_price_derivation": "推导链: forward EPS ¥X × 估值杀 PE Y倍 = ¥XX, 数据来源 verified",
      "verified_source_count": "≥1 (RULE-DATA-VERIFIED 红线, 凭训练记忆填阈值=fatal_flaw)"
    },
    "historical_analog": "引用本 skill 死亡清单(乐视/康美/价值陷阱/抱团瓦解/LTCM/Archegos/Woodford 任一)",
    "sell_trigger_link": "verbatim 匹配 action_plan.sell_trigger 的哪一条"
  },
  "valuation_kill":          { /* 同结构, 加估值杀业务因果(锚公司 PE 下移路径) */ },
  "policy_or_blackswan_kill":{ /* 同结构, 加政策黑天鹅业务因果(实体清单/反垄断/客户毒丸路径) */ },
  "max_permanent_loss_pct": "三场景最大下行(驱动 action_plan.position_limit)",
  "consistency_check": "三场景 sell_trigger_link 都能在 action_plan 找到? true|false",
  "reconcile_with_expectation_gap": "★防 Serenity 孤岛: pre_mortem 三场景必须与 expectation_gap 三锚显式反向校验 — fundamental_kill 推翻了市场已 price-in 的哪个多头共识? valuation_kill 对应'定价充分度'锚的反向?",
  "reconcile_with_business_quality": "★防段永平孤岛: 若 business_quality='好生意', fundamental_kill 必须解释'好生意会怎么变坏'(复购断崖/定价权丧失/客户毒丸); 若周期生意用周期顶点而非线性塌方"
}
```
另需 director 输出 `methodology_used` 数组, 每项 {ruler_id, how_used} narrative 必须能在 thesis/pre_mortem 文中找到对应叙述(防 Goodhart 形式 cite)。

### 浅尝即止反例 vs 深度达标
- ❌ 浅尝："风险包括宏观/政策/行业风险" — 放之四海皆准的废话
- ❌ 浅尝："最大回撤 -30%" — 没有路径、没有触发指标、没有 sell_trigger 闭环
- ❌ 浅尝：只列 fundamental_double_kill 一个场景 — 估值杀+政策杀同样常见，必须三场景齐
- ❌ 浅尝：scenario 一句定性"客户砍单+毛利下滑" — 无 KPI 数字+无业务因果链
- ❌ 浅尝：trigger 用相对偏离"跌 20%/下滑 X%" — 不是绝对阈值
- ❌ 浅尝：downside_price ¥XX 但无 verified_source — 拍脑袋数字(通富 $157B 同型隐患)
- ❌ 浅尝：methodology_used 写"用了巴菲特-逆向"但 thesis 无 invert 叙事 — Goodhart 形式 cite
- ✅ 深度：每场景配 KPI 数字+业务因果链+≥3 绝对阈值+verified_anchor+量化下行+sell_trigger_link+死亡清单类比+reconcile

### critic 必查（GATE rubric 在 §2 基础上加查 9 项）
1. `pre_mortem` 三场景齐 → 缺 = NEEDS_CHANGES, 三场景任一缺 = fatal_flaw
2. `trigger_indicators` ≥3 绝对阈值, 禁相对偏离 → 不达标 = NEEDS_CHANGES
3. `sell_trigger_link` 能在 `action_plan` 找到 verbatim 对应 → 不闭环 = fatal_flaw
4. `historical_analog` 引用本 skill 死亡清单具体案例 → 缺 = NEEDS_CHANGES
5. `max_permanent_loss_pct` 驱动 `action_plan.position_limit` → 不一致 = NEEDS_CHANGES
6. `verified_anchor` 必查: downside_price 推导+trigger 当前观测值有 verified_source URL → 凭记忆填 = fatal_flaw
7. `scenario` 必含 KPI 数字+业务因果链 → 仅一句定性 = NEEDS_CHANGES
8. `reconcile_with_expectation_gap` + `reconcile_with_business_quality` 必填非空 → 缺 = NEEDS_CHANGES
9. `methodology_used.how_used` narrative 能在 thesis 找到对应段落 → 形式 cite = fatal_flaw

## §3 与循环的关系
本 skill 是 `self-evolving-optimization-loop.md` 的 Part 2 + Part 5 的可复用封装。循环每轮：CIO 用 §1 找洞 → 实施 → critic 用 §2 打分 → 提分才沉淀。**目标：让系统从"引用投资理念"真正变成"执行投资理念"。**
