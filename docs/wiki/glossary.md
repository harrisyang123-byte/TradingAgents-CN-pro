# TradingAgents-CN 术语表

## 基金分析 (Fund Analysis)
对基金标的运行多 Agent 辩论，输出与股票分析一致的交易信号（买入/卖出/持有 + 仓位建议）。不是研究报告，是可直接进入 Tier 2 组合分析的结构化决策。输出用 `expected_return`（预期收益率区间，如 "+8%~+15%"）替代股票分析的 `target_price`。

## 股票分析 (Stock Analysis)
对股票标的运行多 Agent 辩论（市场/基本面/情绪/新闻分析师 → 风险管理师 → 交易员），输出交易信号。

## 敞口引擎 (Exposure Engine)
基金持仓拆解 → 底层股票敞口 → 合并矩阵。穿透基金后计算真实行业/个股敞口，合并直接持股 + 基金穿透敞口。

## 存量体检 vs 增量探索
- **存量体检**：现有持仓的操作（hold/add/reduce/sell），基于成本/盈亏/持有时间
- **增量探索**：新候选标的 + 入场条件 + 替代哪只现有持仓

## 资金分配框架 (Capital Allocation)
全局资金约束下处方配对：Σ 买入金额 ≤ 可用现金 + Σ 卖出释放金额。每条 BUY/ADD 标注资金来源，每 SELL/REDUCE 标注资金去向。

## 时机条件 (Timing)
- `immediate` — 立即执行
- `conditional` — 条件触发（等价格/PE分位/事件满足）
- `scheduled` — 定期再平衡

## 情景压力测试 (Stress Testing)
预设 5 种宏观情景（关税升级、RMB贬值、美债加息、A股流动性危机、全球衰退），逐行业估算组合回撤，标记最脆弱持仓。

## 反馈闭环 (Feedback Loop)
新 CI 分析注入历史处方，对比判断对错，从错误中学习。
