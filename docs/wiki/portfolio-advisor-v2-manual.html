组合顾问 v2.0 操作手册

决策卡片 · PE 历史分位 · 基金穿透分析

更新日期：2026-05-24 版本：v2.0 适用环境：TradingAgents-CN

1. 新功能概览

决策卡片

CIO 处方从扁平表格升级为结构化卡片。每条操作独立成卡，含 7 个决策维度：优先级、行业方向、护城河评级、PE 估值锚、逆向压力测试、5 年视角、认知偏差检测。

PE 历史分位管道

覆盖 A 股 / 港股 / 美股三市场，自动回算近 5 年 PE-TTM 百分位，判断当前估值处于历史的什么位置。以进度条可视化呈现。

基金 Tier 2 穿透

基金分析报告正式接入组合顾问流程。分析师评估基金经理质量与策略一致性，策略师检查基金-股票重叠风险，CIO 按基金专属决策标准给出 HOLD / REDEEM / REPLACE 处方。

2. 快速上手

2.1 进入组合页面

  1. 登录 TradingAgents-CN 后，点击左侧导航栏的 "组合管理"（或直接访问 /portfolio）
  2. 页面加载后，你会看到：
    • 顶部 4 个统计卡片（总投入、可用现金、总资产、总盈亏）
    • 仓位分布饼图 + 盈亏贡献条形图
    • 持仓明细表格（可按 A股 / 港股 / 美股 / 基金 筛选）
  3. 确认持仓数据正确后，点击右上角 "组合分析" 按钮

2.2 生成组合建议

  1. 点击按钮后，按钮文字会显示当前进度（"正在初始化..." → "正在生成..." → "完成"）
  2. 整个分析流程包括：
    • L1 宏观裁判 — 行业方向辩论（牛市/熊市分析师 + 宏观交易员 + 裁判）
    • L2 标的裁判 — 个股筛选辩论（基本面/技术/新闻分析师 + 基金经理 + 裁判）
    • L3 组合构建 — 持仓分析师 + 策略师 + 侦察兵三方辩论
    • PE 估值充实 — 为所有持仓计算近 5 年 PE 分位
    • L4 CIO 终裁 — 综合四层数据，输出结构化处方
  3. 完成后右侧弹出 建议抽屉（占屏幕 55%），展示完整分析结果
耗时参考：完整四层分析通常需要 60-180 秒，取决于持仓数量和 LLM 响应速度。

3. 阅读决策卡片

决策卡片是 CIO 处方的核心展示形式，取代了旧版的纯文本/表格。每条操作建议独立成一张卡片。

3.1 卡片优先级

每张卡片左侧有颜色条，一眼可辨紧急程度：

紧急 — 需立即关注（减仓/清仓、重大风险）
建议 — 应该执行（加仓机会、新增优质标的）
参考 — 可关注（观察列表、小仓位试探）

3.3 七大决策字段详解

字段含义数据来源
priority 优先级：urgent / important / optional CIO 综合四层数据判断
l1_context 该标的所处行业的生命周期阶段、Go/NoGo 建议 L1 宏观裁判辩论结果
l2_context 护城河评级 + 标的筛选过滤结果 L2 标的裁判辩论结果
suggested_price 基于 PE 历史分位和 MA20 的安全边际判断 + 建议价格区间 PE 分位数据管道 + CIO 判断
max_loss_pct 逆向验证：如果判断错了，最大亏损百分比 + 触发场景 CIO 逆向思维约束
five_year_view 5 年后这个生意会更好吗？是/否 + 一句话理由 CIO 5 年视角约束
bias_check 认知偏差自检（禀赋效应 / 近因偏差 / 锚定效应 / 讲故事陷阱） CIO 偏差检测约束

3.4 PE 分位进度条

在 suggested_price 区域，系统自动提取 PE 分位数值并渲染为彩色进度条：

0~25% 低估（绿）— 历史底部区域 25~75% 合理（橙）— 历史中枢 75~100% 高估（红）— 历史高位

若某标的无 PE 分位数据（如新股、亏损股、或数据源缺失），进度条不显示，仅展示基于 MA20 的定性描述。

4. 基金持仓评估

4.1 基金分析的两层定位

基金分析聚焦于"基金经理能力"，而非底层股票。因为底层股票已经由 Tier 2 的 L1/L2 裁判独立分析过，基金再做一遍是重复劳动。基金的核心价值在于判断管理人质量、策略一致性、费率合理性。

4.2 三层 Agent 如何评估基金

持仓分析师 (L3) — 基金专项评估

  • 基金经理质量：从业年限、历史业绩、管理规模、是否近期变更
  • 费率合理性：管理费+托管费 vs 同类平均水平
  • 业绩持续性：近 1/3/5 年收益是否持续优于基准
  • 策略一致性：基金名称与实际持仓风格是否一致（如"中小盘"基金重仓大盘股 = 漂移）
  • 赎回/替换判断：浮亏时，区分是市场系统性下跌还是基金本身问题

策略师 (L3) — 基金组合专项评估

  • 基金-股票重叠风险：基金的重仓股是否与你直接持有的个股重叠
  • 管理人集中度：多只基金是否由同一经理/公司管理
  • 费用拖累：总费率对长期收益的侵蚀
  • 流动性差异：场外基金 T+1~T+7 到账 vs 股票 T+1

CIO (L4) — 基金决策标准

操作条件
HOLD 经理任职 > 3 年且业绩稳定、费率合理（股票型 < 1.5%/年）、策略无漂移、无更好的同策略替代品
REDEEM 基金经理变更、连续 2 年以上跑输基准且归因于选股、费率显著高于同类（>2%/年）、规模过大导致策略受限
REPLACE 发现同策略但费率更低、业绩更稳定的替代基金；或基金策略漂移严重偏离配置意图
ADD 某行业/风格暴露不足，且你无法/不愿直接选股，通过被动指数基金或优秀主动基金补足
注意：只有你的持仓中实际包含基金时，基金评估模块才会在 prompt 中出现。纯股票持仓的 prompt 与旧版完全一致，不受影响。

5. 建议抽屉布局说明

右侧抽屉打开后，从上到下依次为：

  1. 决策卡片区 — CIO 操作处方的卡片式展示，按优先级排序（紧急 → 建议 → 参考）
  2. CIO 裁决全文 — 首席投资官的完整判断文本（含最终判断 + 操作处方 JSON）
  3. 可折叠报告区：
    • 市场情报 (L1) — 宏观裁判辩论结果
    • 候选标的 (L2) — 标的裁判筛选结果
    • 分析师评估 (L3) — 持仓分析师逐只评估
    • 策略师评估 (L3) — 组合构建 + 逆向思维
    • 侦察兵评估 (L3) — 组合缺口 + 新标的发现
    • 风险审查 (L4) — 风险总监审查意见
    • 辩论记录 — L3 三方辩论过程
  4. 元数据 — 生成时间戳 + 总耗时（秒）
  5. 历史选择器 — 页面底部可切换查看历史建议

6. 常见问题

Q: 为什么某些持仓的卡片没有 PE 进度条？

可能原因：① 该标的为基金/ETF，PE 管道自动跳过非股票标的；② 该股票为亏损股（EPS 为负），PE 无法计算；③ 港股/美股数据源暂时缺失该标的的分位数据。此时卡片仅展示基于 MA20 的定性判断。

Q: PE 分位数据的覆盖范围？

A 股通过 BaoStock 日线数据回算 5 年 EPS，港股通过 AKShare 年报数据，美股通过 yfinance 年报数据。次新股（上市不足 5 年）按实际上市天数计算。

Q: 基金分析报告为什么没有生成？

基金 Tier 1 分析需要先在基金详情页点击"AI 分析"触发，分析完成后存入 analysis_reports 集合。如果从未触发过分析，Tier 2 组合顾问中该基金会显示"无深度分析报告"。

Q: 为什么组合分析失败？

常见原因：① LLM API 超时或 quota 耗尽；② 持仓数量过多导致 prompt 超出 token 限制；③ 某层辩论死循环。刷新页面后重试，必要时减少持仓数量或切换 LLM provider。

Q: 决策卡片和 CIO 裁决文本是什么关系？

卡片是从 CIO 输出 JSON 中解析出的结构化展示，CIO 裁决文本是 LLM 原始输出（包含推理过程和处方 JSON）。两者内容一致但展示形式不同。

Q: 纯股票持仓用户能看到新功能吗？

能。决策卡片 + PE 分位进度条对所有持仓生效（股票有 PE 分位，基金/ETF 跳过 PE 仅展示 MA20 定性判断）。基金决策标准只在持仓含基金时才出现。
