# 交易纪律教练 (Discipline Coach)

> 买卖前的情绪自检 + 信息验证 + 执行纪律审计。不是替你判断涨跌，而是防止你的情绪替你做判断。

## 解决的问题

你有信息优势（基金动向 + 产业链情报），也有方向判断能力。但执行层面被情绪劫持——这是行为金融学里的"执行落差"（implementation shortfall），几乎每个职业交易员都经历过。

纪律教练的核心作用：**在你的冲动和你的操作之间，插入一个冷静的 Checklist**。

## 工作原理

```
你说"我想买/卖 XX"
       │
       ▼
  纪律教练启动
       │
       ├── Step 1: 收集客观信息基线（读 v4 分析缓存 / X feed / 持仓 / 交易日志）
       ├── Step 2: 判定决策驱动力（客观信息变化 vs 价格波动引发的情绪）
       ├── Step 3: 套用 Checklist（买入 5 问 / 卖出 5 问）
       ├── Step 4: 查历史教训（你上次这样操作的结果是什么）
       └── Step 5: 出决策卡（客观基线 + Checklist + 裁判倾向 + 人性化建议）
```

## Checklist

### 买入 5 问
1. **趋势对不对？** 行业景气度 go/no-go
2. **估值合不合理？** 当前价格 vs target_price，安全边际够吗
3. **仓位会不会太重？** 买后单票 > 20% 或单行业 > 40% 吗
4. **催化剂什么时候兑现？** 有明确时间窗吗
5. **跌 20% 你怎么办？** Pre-mortem：跌了是加/割/装死

### 卖出 5 问
1. **基本面变了吗？** 当初买入的理由还在不在
2. **买入理由还成立吗？** 现在 vs 当初——什么变了
3. **是不是纯粹因为亏了难受？** "错了"和"痛了"不同
4. **卖完涨回去能接受吗？** 如果卖完 +30%，你会怎么想
5. **是纪律还是恐慌？** 当初设的止损触发了吗

## 调用方式

直接用中文对话即可：

| 你说什么 | Coach 做什么 |
|---------|-------------|
| "我想买 XX"、"现在能追 XX 吗" | 快速纪律检查，复用已有缓存，出决策卡 |
| "我想卖 XX"、"XX 跌了要不要走" | 同上 |
| "深辩 XX 买卖"、"全面审视 XX" | 深度检查，重跑 data-desk + 调 critic |
| "加仓 XX"、"减仓 XX" | 同买卖流程，加仓位集中度检查 |

## 裁判三档

| 裁判 | 逻辑 |
|------|------|
| 🛑 **拦** | 5 问 ≥3 个 ❌、纯情绪驱动、历史同类胜率 < 30%、违反仓位铁律 |
| ⚠️ **谨慎放行** | 1-2 个 ❌ 但有方向锚、估值合理但催化模糊、基本面边际变化未到止损 |
| ✅ **放行** | 5 问全过、信息面 + 分析一致支撑、纪律性操作 |

## 交易日志

每次买卖后记录到 `data/v4/_trade_journal.json`，形成你自己的错误模式数据库。事后更新 outcome，Coach 下次会引用历史教训。

## 设计决策

- **为什么不做自动拦截**：硬规则无法覆盖 A 股/港股所有场景（跌停板、除权除息、突发利空），误杀代价高。用户确认纯咨询模式。
- **为什么不做基本面分析**：那是 stock-director 的活。Coach 只做执行纪律层，复用现有分析产物，不越界。
- **为什么加人性化建议**：用户反馈"不要生硬卡片"。共情 + 信息 + 建议的三人称结构，像一个了解你的冷静朋友。
- **为什么用交易日志而非对话记忆**：跨会话保留、结构化可统计（恐慌卖出后 30 天平均涨幅）、不依赖 AI 记忆准确性。
