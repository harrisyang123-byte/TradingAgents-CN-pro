## 探索总结

### 问题核心

当前系统能跑通 L1→L4 流程，但我作为用户不会相信它的结论。原因分两层：

**层1：管道断裂（容易修）**
- msg_clear 导致 Agent 上下文断裂 → JSON 文件总线可解
- 子 Agent 独立看不到矛盾 → 交叉验证规则引擎可解

**层2：内容品质（难修，是这个阶段要解决的）**
```
专业公司产出                         我们的产出
──────────────────────────────────────────────────
L1: 宏观定量+行业轮动+超配/标配/低配   → Go/NoGo 标签
L2: ROE/营收增速/DCF+小盘+价格区间     → 6 维 LLM 评分
L3: 回测/相关性/因子暴露/波动率        → 无
L4: 资金分配方案                       → 持仓操作清单
```

### 目标重新定义

> 不是"让 Tid 顾问跑通"，是"让 Tid 顾问产出的内容能支撑用户做 60 万人民币的资金分配决定"

这意味着每层产出要对标专业投资公司的分析深度。当前 PRD 的指标（5 分钟、36 条处方、1 个矛盾检测）太弱——这些是"跑通"的指标，不是"可信"的指标。

### 待解决的核心问题

**L1 怎么让用户信？**
- 需要宏观数据作为分析起点（PMI/CPI/利率/北向资金）
- 需要量化指标（行业 PE 中位数、ROE 中位数、营收增速）
- 最终说人话：超配/标配/低配/零配，不是 Go/NoGo

**L2 怎么让用户信？**
- Tier1 已经有目标价+止损价+技术分析了——为什么没有被正确消费？因为查询匹配断的
- Scout 推的标的不只是大蓝筹——怎么覆盖中小盘？

**L3 怎么让用户信？**
- 组合构建现在几乎没有内容。策略师自己报"行业标签全部为未知"
- 需要：集中度诊断、回测推演、基金穿透暴露

**L4 怎么让用户信？**
- CIO 的最终处方应该是一份资金分配方案，不是一份持仓操作清单
- 资金分配 = 有来源有去向，有优先级，有时间线

### 方向确认

**方向**: Python 编排 + 9 个子 Agent + 交叉验证 + 每层产出对标专业公司

**不做的**:
- 不改 LangGraph 原代码（留 fix 分支）
- 不搞组合回测/相关性矩阵/因子暴露（v4 再说）
- 不搞实时基金穿透（AKShare SSL 问题待修）

### 已确定的角色定位

**L3 策略师 = 组合诊断报告员**
核心产出是"组合健康度诊断"，不是"策略输出"：
- 行业集中度是否超标（确定性计算）
- 分析师推荐中是否有同方向风险（聚合分析师观点 + 基金穿透）
- 共性的质量担忧（如"75% 的持仓都没有 Tier1 报告"）
- 不输出操作建议 → 那是 CIO 的事

策略师的价值在"把分析师叫醒"：
- 分析师看个股：这条加仓好
- 策略师看全局：你推的 5 只加仓全在科技行业，集中度要到 40% 了

**L1 宏观数据 = 先调工具再判定**
- `get_macro_indicators` → PMI/CPI/利率
- `get_sector_fund_flows` → 行业资金流向数据
- `get_industry_rankings` → 行业涨跌幅排名
- 子 Agent 的输入包含这些工具的返回值，不是让 LLM 凭训练知识猜
