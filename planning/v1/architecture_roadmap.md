# 交易智能体系统 (TradingAgents-CN) 架构演进与实现蓝图

**版本**: v1.0
**日期**: 2026-05-19
**定位**: 全资产智能投资顾问系统的长期演进路线图

## 1. 核心愿景与系统边界

系统定位从“单兵作战的股票分析助手”，升级为**“机构级的全资产（All-Asset）双层组合顾问引擎”**。

*   **宽度拓展**：打破“唯股票论”，横向囊括股票、场外基金、ETF、债券等核心大类资产。
*   **深度穿透**：通过 Tier 1（单体研究员）与 Tier 2（投委会策略师）的双层架构，实现从微观标的到宏观组合的穿透式管理。
*   **方法论沉淀**：建立可持续进化的投资逻辑库，摆脱 LLM 的“常识泛泛而谈”，注入芒格、达里奥等实战约束。

## 2. 核心架构设计：统一抽象与适配器模式

基于你的思考（“底层逻辑一样，但不确定具体实现”），CIO 专家的评估结论是：**Tier 1 的核心调度管线（LLM 推理、结构化输出）完全可以复用，但数据供给层（Data Fetcher）必须使用策略模式（Strategy Pattern）进行解耦重构。**

### 2.1 统一资产抽象 (Universal Asset Abstraction)
为了让 Tier 2 策略师能“无差别”地评估不同资产，我们需要在系统中定义统一的资产接口。无论是股票还是基金，在流入分析引擎前，必须映射为以下标准维度：
*   **表现维度**：历史回撤、波动率、Alpha/Beta。
*   **敞口维度 (Exposure)**：底层究竟买的是什么行业、什么风格？
*   **估值/水位维度**：当前处于历史分位数的什么位置？

### 2.2 Tier 1：分析管线的泛化 (The Polymorphic Tier 1)
目前的 Tier 1 强耦合了“股票因子（如财报、资金流）”。改造蓝图如下：

*   **不变的（复用）**：提示词的分析逻辑框架（SWOT、风险提示）、基于 Checkpoint 的状态管理、结构化 JSON 输出。
*   **变化的（适配）**：
    *   **股票 (Stock)**：拉取财报、K线、新闻面、资金流向。
    *   **基金 (Fund)**：拉取重仓股穿透、基金经理变更、净值回撤历史、同类排名。
    *   **债券 (Bond)**：久期、信用评级、宏观利率决议。

**实现路径**：引入 `AssetAnalyzerProvider`，根据 `instrument_type` 动态挂载不同的数据获取策略，但最终产出格式一致的 `AnalysisReport` 对象。

### 2.3 Tier 2：基于“底层穿透”的投委会 (The Penetrating Tier 2)
Tier 2 不需要知道分析对象是股票还是基金，它只看两样东西：
1.  **Tier 1 生成的标准化报告摘要**（观点是看多还是看空）。
2.  **组合的真实风险敞口 (True Risk Exposure)**。

**难点突破**：Tier 2 必须具备**“打碎基金看股票”**的能力。如果持仓包含 30% 股票A 和 20% 包含股票A 的基金B，Tier 2 必须能计算出对股票A 的总敞口是否超过了红线（如 15%），从而在辩论中提出减仓建议。

## 3. 实施蓝图与里程碑 (Roadmap)

我们将演进路径分为三个阶段，逐步吃透复杂度。

### 阶段一：资产录入与数据底座补平 (Asset & Data Foundation)
**目标**：让非股票资产在系统中”可见、可查、可看”。
1.  **全资产持仓管理**：前端已支持各类型录入，需确保数据库结构 (`instrument_type`) 完全贯通。
2.  **基金数据源接入 (AKShare)**：
    *   实现历史净值获取（解决基金无 K 线的展示问题）。
    *   实现基金概况与季报重仓股获取（为后续 Tier 1 分析储备弹药）。
3.  **基金详情页 (FundDetail.vue)**：前端适配，解决当前基金点击无资源报错的问题，展示净值曲线和基础信息。

> **✅ 阶段一完成 (2026-05-19)**
> - 基金详情页 FundDetail 上线：后端 3 个 AKShare API 端点 + 前端 4 态页面
> - 数据缓存：30 天双级缓存（内存 + MongoDB）
> - 路由：`/portfolio/fund/:code`，持仓列表基金代码可点击跳转
> - 状态覆盖：加载骨架屏 / 空态 / 错误态 + 重试 / 理想态
> - 遗留：历史净值折线图（本期明确排除，放阶段二）

### 阶段二：Tier 1 的泛化与基金分析 (Polymorphic Tier 1)
**目标**：让系统能够对基金写出专业的“研报”。
1.  **分析管线重构**：抽象 `BaseAssetAnalyzer`，分离 `StockAnalyzer` 和 `FundAnalyzer`。
2.  **基金专属 Prompt 设计**：注入评判基金经理、识别风格漂移的专属逻辑。
3.  **单体分析闭环**：在 FundDetail 页面触发基金分析，生成与股票结构一致的 JSON 报告。

### 阶段三：Tier 2 的穿透式重构与方法论进化 (The Ultimate Tier 2)
**目标**：实现真正的全盘组合分析，输出机构级操作建议。
1.  **敞口计算引擎**：在交给 Tier 2 前，先运行一个批处理，将所有基金按季报权重“拆解”为底层行业/股票，汇总出真实的 Portfolio Exposure。
2.  **方法论注入系统 (Agent-driven Optimization)**：
    *   开发一个离线 Agent（如你提到的手动触发的优化 Agent），定期分析历史预测的准确率。
    *   根据反思结果，自动微调 Tier 2 角色（分析师/策略师/侦察兵）的 Prompt，持续补充投资理念。
3.  **全盘辩论上线**：基于真实的底层敞口和统一的报告格式，运行多角色辩论，得出全局调仓建议。

### 远期展望（最低优先级）
*   **自动化资产同步**：探索通过 OCR 解析券商截图，或接入合法合规的第三方记账 API（如类似盈米/有知的外部资产同步工具），减少手动录入摩擦。
