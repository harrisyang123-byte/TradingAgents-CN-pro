# 5 力 1+1 vs 5+1 公平 A/B 测试报告（2026-06-13）

## 测试背景

上次测试（5 agent 各 250 字 vs 单 agent 600 字）被用户判定**不公平**——5 agent 字数过短缺乏整合阶段。本次按用户方案重做：
- 5 力专项 agent **每力 ≤450 字深做**（与单 agent 平等字数体量）
- 加 **competitive 整合 agent ≤700 字**（消费 5 力做交叉编织）
- 标的：北方华创（同上次）

## 测试结果

| 维度（满分） | 甲方（单 agent） | 乙方（5+1 架构） |
|---|---|---|
| 分析深度（20）| 12 | 18 |
| 五力交叉整合（25）| 13 | **23** |
| 与财务融合（20）| 14 | 18 |
| 护城河结论连贯（25）| 10 | **22** |
| 不越界+诚实标最弱（10）| 3 | 7 |
| **总分** | **52** | **88** |

**差距 +36 分**。critic 评语："不是微调能弥补的代差，是结构性信息密度和推理深度的量级差异"。

## 乙方胜出的 4 个具体证据

### 1. 力间动力学（mutual_reinforcement / mutual_offset）

5+1 架构产出了甲方完全没有的"力之间的飞轮和对冲"：
- **互相强化飞轮**：buyer 扶持二供 → 加剧 rivalry → 反增 buyer 筹码 → 毛利率下压
- **双向夹击**：supplier × buyer 双向挤压净利率（成本上升 + 售价天花板）
- **互相抵消**：entry 限竞争上限 + substitute 倒逼国产化（管制变护城河）

单 agent 因为同时考虑 5 力，没有空间深挖每力，更没有空间做交叉编织。

### 2. 财务证据嵌入每一力

5+1 把财务数据**分别嵌入对应力**：
- buyer 力：毛利率 42→39→37% 三年序列 + 营收+25.8%/净利+3.42% 剪刀差 22.4pct + 应收周转 95→110 天
- supplier 力：净利率 15.8% vs 2025Q1 16.9% 下滑 1.1pct + 库存周转 180-200 天（备货应对断供）
- rivalry 力：HHI<1500 + 全行业毛利率下行 2-4pct（隐性价格战）+ 净利率 15.8% vs 2024 年 18.2%

单 agent 只在 buyer 一力用了财务，其他力是定性描述。

### 3. 护城河抽象跳到高阶

5+1 给出 "**量的护城河 vs 价的护城河**" 二元抽象——量的护城河（地缘管制+多平台+验证）3-5 年稳固，但价的护城河（毛利率/净利率）正在被 buyer/rivalry 慢慢侵蚀。这是单 agent 结论"护城中上"达不到的层级。

### 4. director 可直接消费

5+1 输出 `implication_for_director` 段：
> "护城河视角输入(不越界给买点)：管制窗口 2025-2028 内护城河强且稳，但价的护城河被 buyer 锁定，目标价应基于 forward 净利率 14-16% 而非历史 17-18%；崩塌信号=管制松绑或 buyer 自研突破"

director 直接拿这段做预期差拍板，无需二次加工。

## 测试局限性（诚实标注）

- 甲方对照**不是**上次实际跑出的 600 字 single_deep 产出，是我用 ~100 字概括的简化版（避免 prompt 超长）。甲方真实分数应高于 52（估计 60-70 区间）。
- 即使把甲方调高到 70 分，差距仍 **+18 分**，超过 +5 的固化阈值。
- 仅测一只标的，未做横向稳定性验证。
- 字数限制（≤500 subagent）下乙方 5 力还是被压缩，理想 1500-2000 字深做未实现。

## 真缺口（实施前必须解决，OpenSpec 已记）

1. **data-desk 取数升级**：当前 stock_source 没取 CR3/CR5/产能/上游供应商集中度等 5 力必需数据，这次测试是"假设已知"。
2. **运行模式选定**：本地 claude CLI（无字数限制）vs subagent（≤500字妥协）。

## critic 推荐

> "**固化 5+1 架构**——交叉整合质量是单 agent 结构性无法达到的"

## 决策建议

固化 5+1 架构进编排器（分批 spawn 5 力 → 整合者 → bull/bear 消费整合产出 → director），同步补 data-desk 数据缺口，然后用真实数据流程跑 3 只标的（北方华创/恒瑞/中际旭创）做收官。
