# Chokepoint Framework — 供应链瓶颈投资框架（v4 行业/个股层增强）

> 状态：设计已对齐（2026-06-09），待据此改 prompt + 跑首个完整行业验证。
> 来源：借鉴 X 投资博主 Serenity（@aleabitoreddit）的 "Chokepoint Theory"（供应链瓶颈理论）。
> 归属波次：Wave 3 权益深链（行业层 + 个股层）的能力增强。与 §8.1（full-analysis-plan）登记一致。

---

## 0. 一句话定位

**在景气行业里，自下而上逆向工程产业链，找到那个"物理不可替代 + 供给极度集中 + 产能扩不出 + 价值卡位"的咽喉环节，在市场发现前提前布局受益标的。**

这是对现有"景气度 × 安全边际"框架的**下游深化，不是替代**（详见 §4 关系与张力）。

---

## 1. 核心：瓶颈（Chokepoint）的四维判定标准

不能凭"感觉像卡脖子"，必须按四个可判定维度逐环节打分。**四维同时偏强才算真 Chokepoint，缺一个就降级。**

### ① 不可替代性（Irreplaceability）—— 下游能不能换掉它？
| 分级 | 标准 | 例 |
|------|------|----|
| 高 | 物理定律 / 核心专利锁死，替代需颠覆性突破 | Soitec SOI Smart-Cut 专利、EUV 光刻、CoWoS |
| 中 | 技术可替代但工程难度高、认证周期长 | 高端封装基板 |
| 低 | 多条成熟替代路径 | 通用元件 |

**强制配套**：必须给 `substitution_risk`（替代路径评估）——是否有正在成熟的替代技术？时间表？这是 Serenity 方法论的命门（见 §5 局限）。

### ② 供给集中度（Supply Concentration）—— 全球几家能做？
| 分级 | 标准 |
|------|------|
| 极高 | 1-2 家垄断，CR1 > 70% |
| 高 | 3-5 家，CR3 > 80% |
| 中 | 5-10 家 |

数据多为二手（行业报告/年报市占率），**大部分只能标 estimated**，禁止编造精确数字。

### ③ 产能刚性（Capacity Rigidity）—— 需求翻倍，多久扩得出？
**这是瓶颈的命门**：需求来了扩不出产能才叫卡脖子。
| 分级 | 标准 |
|------|------|
| 强 | 扩产 > 2 年 + capex 门槛极高 + 过去长期投资不足 |
| 中 | 1-2 年 |
| 弱 | < 1 年可快速响应 |

### ④ 价值卡位（Value Capture）—— Serenity 选股精髓
"占下游成本比例极低，但断供则整条线停摆" = 议价权最强、提价下游无感、自身利润弹性最大。
- 判定：BOM 成本占比（越低越好）× 不可或缺性（越高越好）
- 例：高纯红磷在芯片成本里占比微乎其微，但断供整条线停摆

## 2. 拆解方法：自下而上逆向工程

从终端爆发需求出发，逐层向下钻，每层问"这层谁卡脖子"，直到触达不可再拆的物理/材料/设备瓶颈。

```
终端爆发需求(AI算力/人形机器人/...)
  → 系统级(GPU集群/机器人本体)
    → 部件级(光模块/减速器)
      → 关键器件(CPO/激光器/CoWoS)
        → 材料/设备级(SOI衬底/MBE设备/高纯材料/EUV光刻机)
                            ↑ 越往底层越容易出现物理卡脖子
```

**A/B 实测验证（见 §6）**：专职瓶颈分析师能下钻到材料/设备物理底层（ABF载板、HBM TSV硅通孔、键合材料），而兼职的研究员往往停在"环节"浅层。下钻深度 = 框架价值所在。

## 3. 角色分配（按两轮实测定稿：专职角色 + 混合分队深挖）

> ⚠️ 经两轮实测迭代定稿（2026-06-09）：
> - **第1轮 A/B**（§6.1）：推翻"增强不新增"直觉 → 确认需**专职瓶颈分析师**（专职拆解比兼职深得多）。
> - **第2轮 单兵vs分队**（§6.2）：确认专职分析师**单兵拆全链仍不够深** → 对 top 瓶颈需**派专项调研员深挖**才能挖到可执行的标的层（实测专人挖出了单兵遗漏的最纯正标的盛合晶微 + 买点逻辑）。

### 行业层：瓶颈分析师出骨架 + 主agent对top瓶颈派专项调研员（混合分队）

受 subagent 不嵌套硬约束，"分队"由主agent(director)编排，两层实现三层效果：

```
① 行业瓶颈分析师(subagent) → 出全链 chokepoint_map 骨架 + 标出 top 1-2 真瓶颈
② 主agent(director) → 联网取 top 瓶颈的深度数据 → 对每个 top 瓶颈派 1 个专项调研员(subagent)深挖
③ 各专项调研员(subagent, 并发≤3) → 单环节挖到标的层(供给格局/产能卡点/替代时间表/标的真实卡位/买点)
④ 主agent(director) → 汇总 + 二次核实关键声明(标的代码/份额/良率) → 最终 chokepoint_map
```

| 角色 | 职责 | 产出 |
|------|------|------|
| 行业研究员（现有） | 行业景气 go/nogo + 等级 | 景气判断 |
| **行业瓶颈分析师（新增, subagent）** | 全链逆向工程 + 四维判定，**广度优先**出骨架 + 标 top 瓶颈 | `chokepoint_map` 骨架 + `top_chokepoint` |
| **瓶颈专项调研员（新增, 主agent按需派, subagent）** | 对单个 top 瓶颈**深度优先**挖到标的层 | 单环节深度报告（供给/产能/替代/标的卡位/买点）|
| 行业 bull/bear（现有） | 多空辩论 | bear 增「替代路径专项攻击」 |
| 行业 director（主agent） | 编排分队 + 核实 + 拍板 | 综合景气+瓶颈，核实专项调研员的 estimated 声明 |

**派不派专项调研员的判据（控成本，避免无脑全员）**：
- 只对瓶颈分析师标出的 **top 1-2 真瓶颈**派专项调研员深挖（边际递减——长尾环节单兵带过即可）。
- top 瓶颈定义：四维同时偏强 + 在组合可投范围内有标的（A股/港股/QDII）。
- 数据核实责任在 director：专项调研员深但 estimated 多，关键声明（标的代码/产能份额/良率）必须主agent二次核实再落盘。

### 个股层

| 角色 | Chokepoint 注入 |
|------|----------------|
| 个股 Scout | 消费 `chokepoint_map`，优先瓶颈环节标的，打 Chokepoint 6 维评分（§说明见下）|
| 个股 bull | 用"瓶颈溢价"逻辑（需求爆发 × 供给受限 = 利润弹性）|
| 个股 bear | 专项攻击 `substitution_risk`（替代路径）+ 产能扩张 + 估值透支 + 流动性 |

**个股 Chokepoint 6 维评分**（每维 1-5 加权）：不可替代性 / 供给集中度 / 产能刚性 / 价值卡位 / 需求确定性 / **市场定价效率**（越被机构忽视分越高 = 预期差空间）。

## 4. 与现有框架的关系：增强 + 一处健康张力

```
第1层(不变)：行业景气 go/nogo —— 要不要进这个行业（行业研究员）
第2层(Chokepoint增强)：go行业内拆产业链定位瓶颈环节 —— 买这行业的哪个环节（瓶颈分析师）
第3层(个股)：瓶颈环节里选公司 + 安全边际把关买点 —— 买谁、什么价（Scout+多空+director）
```

**唯一张力（健康的）**：Chokepoint 偏好"机构忽视的冷门标的"（预期差=收益来源），但瓶颈股常**估值不便宜**（稀缺溢价）；"安全边际"框架又要求不追太贵。两者在个股 director 裁决时拉扯——这是**健康对立**（类似多空辩论）：Chokepoint 管"选最强环节"，安全边际管"别买太贵"，director 平衡。不是冲突，是互补制衡。

## 5. 市场分层落地（按用户实际可投范围）

> 用户可投：A股直接 / 港股直接 / 海外通过 QDII·基金平台间接。比 README 旧边界（"组合顾问个股层只跑A股"）宽得多。

| 标的类型 | 可投性 | 落地方式 |
|---------|--------|----------|
| A股个股 | ✅ 直接 | Scout 直接推 |
| 港股个股 | ✅ 直接 | 模式A下主agent可直接分析港股（不受系统Scout只认A股限制——手动驱动）|
| 海外个股（瑞典/法国/台湾/韩国等） | 间接 | **不直推个股，推对应 QDII / 主题基金获取敞口** |

**实测示例**（AI算力瓶颈 → 可投路径）：
- CoWoS 先进封装 → A股 长电科技(600584)/通富微电(002156)；台积电/日月光走台股或半导体 QDII
- HBM → SK海力士/三星 走韩国/半导体 QDII
- 光互连 CPO → A股 中际旭创(300308)/新易盛(300502)/天孚通信(300394) 直接可买
- EUV 设备 → ASML 走荷兰/半导体 QDII；A股 北方华创(002371)/中微公司(688012) 做国产替代敞口

**关键认知**：很多真正的物理瓶颈（SOI 衬底、MBE 设备）不在 A股，但能通过港股/QDII 触达——这反而让框架更有用。

## 6. 实测记录（2026-06-09，两轮，定角色架构的实证依据）

### 6.1 第1轮 A/B：融合 vs 专职（定"是否新增角色"）

**方法**：同一行业「人工智能算力」，喂相同数据背景（CoWoS/HBM/CPO/2-3nm 瓶颈现状），跑两组 subagent 对比瓶颈拆解质量。

| 维度 | A 组（融合：研究员兼景气+瓶颈）| B 组（专职瓶颈分析师）|
|------|------|------|
| 拆解深度 | 4 环节，停"环节"层 | **6 环节，下钻到材料/设备底层**（ABF载板/HBM TSV/EUV/键合材料）|
| 替代路径评估 | ❌ 无 | ✅ 每环节都有 |
| 逆向工程路径 | 无显式链 | ✅ 终端→系统→部件→器件→材料/设备 |
| 标的精准度 | 较泛 | A股/港股/QDII 分层标注 |
| 收敛判断 | 列4个 | ✅ 明确 top=CoWoS，对比"HBM≥3家 vs CoWoS单一垄断" |

**结论**：B（专职）显著胜出 → 确认需专职瓶颈分析师。此结论**推翻了最初"增强不新增"的直觉判断**。

### 6.2 第2轮 单兵 vs 分队：专职单兵 vs 专项调研员深挖（定"要不要分队深挖"）

**方法**：固定 CoWoS 单一环节，对比"单兵全链分析师对CoWoS的一行输出"（§6.1 B组）vs"专项调研员只挖CoWoS到最深"。

| 维度 | 单兵（全链，一行）| 专人（CoWoS专项深挖）|
|------|------|------|
| 供给格局 | "供给极高" | TSMC~90%、三星I-Cube良率30-40%/落后2代/月产<5000片、Amkor无interposer能力 |
| 产能卡点 | "刚性强" | 拆到具体工艺步：硅中介层(65nm光刻+深TSV)、TCB键合设备(K&S/Besi交期12-18月)、LSI桥接 |
| 替代时间表 | 一句 | 玻璃基板2027样品/2029小批/2030量产、InFO_SoW、FOPLP 分别列威胁等级 |
| **A股标的** | 列名(长电/通富) | **挖出单兵遗漏的盛合晶微**(国内唯一CoWoS-like全流程OSAT,承接寒武纪/昇腾)+各标的真实技术代差/收入占比/客户 |
| 买点 | 无 | 催化剂+估值锚(长电40-50x/盛合80-100x)+买点(费半-10%回调低吸,首仓≤3%) |

**结论**：专人深挖增量巨大，关键增量落在**可执行的标的层**（挖出单兵遗漏的最优标的+买点）→ 确认对 top 瓶颈需派专项调研员深挖（§3 混合分队）。**限定**：①只对 top 1-2 瓶颈派人（边际递减、控成本）；②专人 estimated 多，director 须二次核实关键声明。

## 7. 诚实的局限（必须随框架一起记，防误用）

1. **数据质量天花板**：①②④ 多为定性+二手信息，达不到宏观数据的 verified 级。强制每个瓶颈判断标证据等级，严格区分"看起来像瓶颈"与"verified 瓶颈"。
2. **单一路径依赖**（Serenity 的阿喀琉斯之踵）：他押"CPO 是唯一路径"，技术路线一变整套逻辑崩。所以 bear **必须**给替代路径评估，不可省（已固化为 §1① 的 substitution_risk 强制字段）。
3. **流动性**：真瓶颈公司常是冷门小盘，流动性差、波动大，与组合规模/风格匹配度要单独评估（个股 bear 攻击点之一）。
4. **海外个股不可直持**：走 QDII/基金间接，存在跟踪误差、费率、申赎限制——非完美复制瓶颈标的的 alpha。
