# v4 "单兵 → 分队" 升级审查（squad-vs-solo audit）

> 目的：系统排查 v4 全流程所有 LLM 环节，找出"一个 agent 全包、但拆成多专项 subagent 分队会显著更强"的环节。
> 方法论来源：chokepoint-framework.md §6.2 实测确立的"混合分队深挖"——单兵拆全链会摊薄，专项调研员深挖单点能挖到可执行层。
> 状态：2026-06-09 首次审查。

---

## 评估框架（4 判据，全satisfy才是强候选）

| 判据 | 含义 |
|------|------|
| ① 多维性 | 任务是否由多个**独立**深度子任务组成（每个都需要专门挖）|
| ② 摊薄风险 | 单兵全包是否会导致每一维都"浅尝辄止"|
| ③ 增量落地 | 分队的增量是否落在**可执行层**（像 CoWoS 专人挖出盛合晶微+买点那样，而非只是更啰嗦）|
| ④ 成本可控 | 子任务数有限（≤3-4），不会 subagent 数量失控 |

> 注：裁决/拍板/配比类环节（director/allocator）天然是**单点决策**，不能分队（多个agent无法共同拍一个板），一律排除。

## 候选排序（按升级价值）

### ★1. 个股层缺多维基本面分析师（最强，结构不对称的硬伤）
- **问题**：大类层有 3 分析师（macro/flow/policy）打底再辩论；个股层却**直接 bull/bear/director，没有任何基本面分析师**。结构严重不对称。
- **个股基本面天然多维**：财务健康（资产负债/现金流/盈利质量）、竞争格局（护城河/市占/对手）、成长驱动（需求/产能/新品周期）、估值（PE/PB/DCF/历史分位）、治理/管理层、Chokepoint卡位（已在 Scout）。
- **单兵 bull/bear 直接辩论的缺陷**：没有扎实的中立多维基本面底座，多空容易各执一词、流于观点而非事实。
- **对标 TradingAgents**：它的精髓正是 fundamentals/sentiment/news/technical 四分析师并行 → 再 bull/bear 辩论 → director。我们个股层缺了这个底座。
- **升级方案**：个股层引入"3 分析师"分队（财务 / 竞争格局 / 估值），并行深挖 → 喂给 bull/bear 辩论 → director。与大类层范式对齐。
- **待实测验证**（§本轮测试）。

### 2. 行业瓶颈深挖（已定，本次成果）
chokepoint-framework §3 混合分队。

### 3. 行业景气分赛道（中）
多细分赛道的大行业，单兵景气判断粗。可在景气研究员下，对 top 赛道派专项。优先级低于个股，登记备用。

### 4. data-desk 并行取数（低，受限）
subagent 无 web，只能主agent取；已在并行 web_search，无需结构改造。

## 本轮测试计划

**测最强候选：个股层 单兵 vs 分队**
- 标的：中际旭创(300308)——CPO/光模块龙头、在 chokepoint_map 内、A股可买、公开数据充分。
- 对照组（单兵）：一个 agent 全包"基本面+竞争+估值+评级"。
- 实验组（分队）：财务分析员 + 竞争格局分析员 + 估值分析员 并行 → 对比深度。
- 判据：分队是否在每一维都挖出单兵摊薄掉的可执行细节（具体财务比率/对手份额/估值分位+买点）。

---

## 本轮测试结果（2026-06-09，中际旭创 300308）

**单兵**（一人全包基本面+竞争+估值+评级）：各维概括正确但浅；给"增持/目标价220-260元"。

**分队**（财务/竞争/估值 三专项并行深挖）：
- 财务专项：杜邦拆解 + 现金/净利比0.8-0.88(盈余质量非顶级) + **5大红旗**(应收增速70-80%超营收60%/存货100亿减值/客户集中75%+/泰国良率/1.6T备料减值)——单兵全未提。
- 竞争专项：800G份额35-40%、1.6T份额45-50%细分 + 与新易盛差距(规模2.5-3倍/认证5年壁垒) + 上游EML依赖Coherent议价权弱(参股源杰自供30-40%) + CPO威胁分2年内<5%/3-5年观察Nvidia。
- 估值专项：PE近5年分位>95% + 三情景(bull690/base460/bear275元) + PEG1.33 + vs海外溢价60-80% + 买点320-370/止损280。

**决定性发现**：单兵给"增持/220-260元"，但估值专项指出当前股价420元已price-in乐观、PE分位>95%、安全边际薄、买点应<350；财务专项挖出的应收/存货/客户集中红旗单兵一个未提。**分队不只更深，还纠正了单兵的乐观偏差**——印证"个股层缺中立多维基本面底座→单兵易流于乐观观点"。

**结论**：✅ 验证通过。个股层应引入"多维基本面分析师分队（财务/竞争/估值）"打底，再 bull/bear 辩论 → director，与大类层 3 分析师范式对齐，修复结构不对称。注：分队 estimated 多，director 须二次核实关键财务数据再落盘。

## 定稿：v4 三处"分队"架构（统一收口）

| 层 | 分队 | 状态 |
|----|------|------|
| 大类层 | macro/flow/policy 3分析师 | 已有 |
| 行业层 | 瓶颈分析师 + top瓶颈专项调研员（混合分队）| 本轮新定（chokepoint §3）|
| **个股层** | **财务/竞争/估值 3分析师**（新增，修复结构不对称）| 本轮实测验证，待落地 prompt |

通用原则：分析/研究类多维环节→分队；裁决/配比类单点决策→单兵 director 不变；data-desk 受 web 限制不分队。
