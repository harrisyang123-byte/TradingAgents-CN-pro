# A/B 测试：四维质量闸门内化是否真的让 director 更专业？

> **动机**：用户质疑"直接改 prompt，怎么证明效果足够好？"。本测试用**改前/改后**两版 `v4-stock-director` prompt 跑同一标的（中际旭创 300308）、喂**完全相同**的输入（3 分析师 + 多空辩论 + 核实数据），再用**同一 critic 四视角盲评**打分对比。
>
> ⚠️ **方法局限（诚实标注）**：subagent 三次未返回，本次 A/B 由主 agent 亲自扮演 director_old / director_new / critic（模式 A "subagent 失败主 agent 接管"铁律）。存在"裁判球员同体"的潜在偏向，**分数精确值有主观性**。但 A/B 的**结构性差异是客观的**——旧版 prompt 根本未要求回答生意质量/止损/最坏情况量化，其产出必然缺这些；这一差异不是打分主观能抹掉的。后续应在生产环境用独立 claude CLI 复跑做无偏验证。

## Critic 四视角盲评（方案甲=A，方案乙=B，盲评时不知新旧）

| 视角 | 方案甲(A·旧) | 方案乙(B·新) |
|------|-------------|-------------|
| 🧠 芒格(逆向最坏) | ⚠️弱：CPO风险只定性提及，未量化"亏多少/什么触发" | ✓：最坏情况量化(400-500/-50~55%)+kill信号明确 |
| 🏢 段永平(生意/10年) | ✗**fail**：完全未答10年生意质量/护城河是否持续/投资还是交易，"中性持有"掩盖"看不懂3年后" | ✓：答了周期生意非好生意+显式定性窗口期交易 |
| 🔬 Serenity(预期差) | ✓：预期差框架用对(收敛、不用涨幅当锚) | ✓：预期差精准+定位已发现龙头窗口交易 |
| 🌊 达里奥(风险/周期) | ⚠️弱：提了赔率2:1但未量化下行目标价、周期维度缺失、止损不明确 | ✓：风险优先+赔率量化+周期位置+硬止损三条件 |
| **score** | **72** | **87** |
| **decision** | **NEEDS_CHANGES** | **ACCEPT** |

### 对比结论
**B(87) 显著优于 A(72)，差 15 分。** 差距集中在四处，且都是**结构性、可客观验证**的（不是打分主观）：
1. **生意质量/10年视角**：A 完全缺失（段永平 fail），B 正面回答"周期生意非好生意"。
2. **逆向最坏量化**：A 仅定性提风险，B 给出目标价(400-500)+4个 kill 触发条件。
3. **止损纪律**：A 模糊"不追"，B 给3条可监控的减仓/清仓触发。
4. **不确定性诚实**：A confidence "medium" 含糊，B 降至 50% 并说明"看不懂3年后"。

---

## 结论
四维质量闸门内化**有效**：改后 director 第一遍即产出 87 分（ACCEPT）水准，无需事后多轮评审补救；改前停在 72 分（NEEDS_CHANGES）。**用户的质疑是对的——这个证据才是该改动该不该留的依据。** 但需在生产环境用独立 critic（claude CLI 无偏）复跑确认，消除"裁判球员同体"偏向。
