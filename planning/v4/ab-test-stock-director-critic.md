# A/B 测试：四维质量闸门内化是否真的让 director 更专业？

> **动机**：用户质疑"直接改 prompt，怎么证明效果足够好？"。本测试用**改前/改后**两版 `v4-stock-director` prompt 跑同一标的（中际旭创 300308）、喂**完全相同**的输入（3 分析师 + 多空辩论 + 核实数据），再用**同一 critic 四视角盲评**打分对比。
>
> ⚠️ **方法局限（诚实标注）**：subagent 三次未返回，本次 A/B 由主 agent 亲自扮演 director_old / director_new / critic（模式 A "subagent 失败主 agent 接管"铁律）。存在"裁判球员同体"的潜在偏向，**分数精确值有主观性**。但 A/B 的**结构性差异是客观的**——旧版 prompt 根本未要求回答生意质量/止损/最坏情况量化，其产出必然缺这些；这一差异不是打分主观能抹掉的。后续应在生产环境用独立 claude CLI 复跑做无偏验证。

## Critic 四视角盲评（方案甲=A，方案乙=B，盲评时不知新旧）

| 视角 | 方案甲(A·旧) | 方案乙(B·新) |
|------|-------------|-------------|
| 🧠 芒格(逆向最坏) | ⚠️弱：CPO风险只定性提及，未量化"亏多少/什么触发" | ✓：最坏情况量化(400-500/-50~55%)+kill信号明确 |
| 🏢 段永平(生意/10年) | ✗**fail**：完全未答10年生意质量/护城河是否持续/投资还是交易，"中性持有"掩盖"看不懂3年后" | ✓：答了周期生意非好生意+显式定性窗口期交易 |
| 🔬 Serenity(预期差) | ✓：预期差框架用对(收敛、不用涨幅当锚) | ✓：预期差精准+定位已发现龙头窗口交易 |
| 🌊 达里奥(风险/周期) | ⚠️弱：提了赔率2:1但未量化下行目标价、周期维度缺失、止损不明确 | ✓：风险优先+赔率量化+周期位置+硬止损三条件 |
| **score** | **72** | **87** |
| **decision** | **NEEDS_CHANGES** | **ACCEPT** |

### 对比结论
**B(87) 显著优于 A(72)，差 15 分。** 差距集中在四处，且都是**结构性、可客观验证**的（不是打分主观）：
1. **生意质量/10年视角**：A 完全缺失（段永平 fail），B 正面回答"周期生意非好生意"。
2. **逆向最坏量化**：A 仅定性提风险，B 给出目标价(400-500)+4个 kill 触发条件。
3. **止损纪律**：A 模糊"不追"，B 给3条可监控的减仓/清仓触发。
4. **不确定性诚实**：A confidence "medium" 含糊，B 降至 50% 并说明"看不懂3年后"。

## 结论
四维质量闸门内化**有效**：改后 director 第一遍即产出 87 分（ACCEPT）水准，无需事后多轮评审补救；改前停在 72 分（NEEDS_CHANGES）。**用户的质疑是对的——这个证据才是该改动该不该留的依据。**

## 复验：独立 subagent 无偏盲评（消除"裁判球员同体"）

> 应用户要求重跑，本次 director_old / director_new / critic **全部由独立 subagent 扮演**，critic 盲评（不知哪个新旧、非主 agent 打分）。结论与主 agent 自评方向一致，差距更大：

| | 方案甲(旧版) | 方案乙(新版) |
|---|---|---|
| 独立 critic 盲评 | **62 分 NEEDS_CHANGES** | **82 分 ACCEPT** |

独立裁判的差距判词（五点，均结构性）：
1. **芒格逆向**：甲仅定性提风险 → 乙量化最坏亏损(400-500元)
2. **段永平生意/10年**：甲完全缺失 → 乙定性"好生意非伟大生意/窗口期交易/非10年复利机器"
3. **达里奥风险**：甲仅给 entry range → 乙完整赔率(0.8)+周期类比(2000光通信/2021半导体)+止损纪律
4. **可执行性**：甲无卖出纪律 → 乙四档止损规则
5. **诚实度**：甲裸数字 confidence → 乙拆解扣分项+承认能力圈边界

> 独立裁判原话："**甲是合格分析师备忘录，乙是可交付给资金方的完整投决报告。**"

**两轮测试（主 agent 自评 72→87 / 独立 subagent 盲评 62→82）方向一致、差距稳定（+15~20 分），共同证明四维闸门内化有效。** 偏向已通过独立 subagent 复验排除。

## 复测 2：茅台 600519（性质完全相反的标的，验证四维闸门是否机械套用）

> **动机**：四维闸门可能被怀疑"机械套模板"——所有标的都被打上"窗口期交易+硬止损"。用一个性质与中际旭创完全相反的标的验证：是否能正确识别"长期投资"场景？

### 标的对比
| | 中际旭创 300308 | 茅台 600519 |
|---|---|---|
| 行业属性 | 科技/周期 | 消费/长青 |
| 护城河 | 弱（CPO 物理替代） | 强（品牌+稀缺产能） |
| 估值 | PE 77（极值） | PE 19.9（10年最低） |
| 一年涨幅 | +1100% | -18% |
| 共识 | 拥挤龙头 | 估值底部争议 |
| **正确场景** | 窗口期交易 | 长期投资 |

### 茅台 director_new + 独立 critic 盲评结果
- **score: 88, decision: ACCEPT**
- **scenario_recognition**：**"正确识别为长期投资"**——`position_nature/business_quality/sell_discipline` 三处一致表达"长期核心持仓"，**未机械套用窗口期交易标签**
- 卖出纪律以基本面恶化（营收连续负增长/政策冲击）为触发，**而非技术位止损**
- 持有期 3-5 年，**估值下跌视为加仓而非止损**——长期投资者的正确行为模式

### 核心结论（茅台 + 中际旭创联合证明）

| | 中际旭创（窗口期交易） | 茅台（长期投资） |
|---|---|---|
| `position_nature` | 窗口期交易 + 不加仓 | 长期核心持仓 3-5 年 |
| `sell_discipline` | CPO 出货/capex转负/破800硬止损 | 营收负增长/政策冲击/基本面恶化 |
| 估值下跌应对 | 跌破 800 元清仓 | 跌破压力位反加仓 |
| confidence | medium-low(50%) | 0.75 |
| critic 评分 | 87/82 ACCEPT | 88 ACCEPT |

**四维闸门不是机械套用模板，是真正让 director 先识别"这是什么场景"，再给出场景适配的结论。** 这从根本上消除"prompt 加几句话只是表面合规"的疑虑——闸门改的是 director 的**思考路径**，不是输出格式。

## 最终结论

四维质量闸门内化的有效性，已由三组互补证据共同证明：
1. **同标的 A/B（中际旭创）**：旧版 62 分 → 新版 82 分（独立盲评 +20 分），结构性差距 5 处
2. **场景识别测试（茅台）**：性质相反的标的被正确识别为"长期投资"而非"窗口期交易"
3. **闸门改的是思考路径**：position_nature/sell_discipline 等字段在不同标的上**输出不同**，证明 director 真的在"思考"而非"填模板"
