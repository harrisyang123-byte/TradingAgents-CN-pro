# 交易无人知晓的瓶颈 — Serenity 五因子模型(产业链上溯式投资)

> **2026-06-15 用户拍板固化为永久铁律**。本框架是 chokepoint-framework 的方法论灵魂,纠正"用研报找 alpha"的根本性错误。
> 核心一句话:**不押注显而易见的大明星,而是在确定性技术长周期中,精准找到那个"缺了它整个产业链转不动"的小环节,在市场后知后觉前提早介入。**

---

## 一、致命纠错(为什么之前方向错了)

**❌ 错误做法**:用券商研报/市场热点"验证"瓶颈标的。
**为什么错**:研报覆盖的 = 市场已知的 = 高关注度 = 价格已反映 = **没有 alpha**。研报是"市场已经知道的事",而 alpha 只存在于"市场还不知道的事"。

**❌ 错误做法**:把"卡位硬但当前利润未兑现"的标的按高 PE/亏损一律淘汰。
**为什么错**:违背"提早介入"。利润未兑现恰是市场没认识到的阶段。该用"价值可捕获 + 催化剂"区分"现在买"vs"还太早",而非简单按当前财务砍掉。

**❌ 错误做法(2026-06-15 用户纠正)**:把"低关注度"当成**唯一硬门槛**,把高关注度/大市值的龙头一律降级排除。
**为什么错**:目标是**盈利(绝对收益)**,不是教条地"只买小紫苏叶"。**被错杀的优质卡位龙头也是大机会**——用户实例:中际旭创 ¥88 买入(后涨至 ¥1149,13 倍),它当时是高关注度龙头,但被系统性杀跌错杀时正是黄金买点。**低关注度只是"未被充分定价"的一种来源(信息不对称),被错杀(预期差)是另一种来源**。核心标准应是**"产业链分析中未被充分定价"**,不是"关注度高低"。

**✅ 正确做法**:靠**缜密推理**从公开碎片信息(行业研究/学术论文/专利文件/客户名单/产能地图/上游矿源等非结构化数据)交叉比对 + 演绎推理,拼出高信念推论。**两类目标都要**:① 低关注度紫苏叶(信息不对称未定价) ② 被错杀的卡位龙头(预期差未定价)。

---

## 二、三条心法原则

### 原则一:以确定性大主线为背景
只聚焦未来 **2-5 年确定性扩张**的产业方向——具备产业级资本开支、技术路线已落地、巨头持续投入。
- 当前确定性主线:**AI 数据中心 / 人形机器人 / 800V 直流供电 / 自研 AI 芯片(ASIC) / 推理带宽**
- 关注的不是"今天市场炒什么",而是"未来几年一定会发生什么"。

### 原则二:从上到下的产业链拆解
确定大趋势后,**不直接选股**,而是把产业链上中下游逐层拆开,寻找哪一环节会成为**产能/技术/认证周期的物理瓶颈**。
- 拆解路径:终端需求 → 整机 → 模组 → 核心部件 → 关键材料 → 上游设备/矿源
- 在每一层问:这一环节"扩产要多久""认证要多久""有没有替代路径""全球能做的有几家"

### 原则三:用碎片拼出"市场还不知道的事"
依靠公开零散信息演绎推理,拼出高信念推论,**等待市场后知后觉地追上来**。
- 信息源:专利文件(谁在布局)、客户名单(谁绑定了谁)、产能地图(谁在扩产/扩不动)、上游矿源(谁卡了原料)、学术论文(技术路线往哪走)、招标公告、海关数据、扩产公告
- **不是检索研报结论,是自己做侦探**。

## 三、五因子模型(④⑤为硬约束;①②③组合判定"未被充分定价")

> **2026-06-15 修正**: 原"③低关注度"是硬门槛过于教条(会错杀被低估龙头)。改为核心判定 **"未被充分定价"**, 有两条来源任一成立即可: **(a) 低关注度**(信息不对称, 紫苏叶) **或 (b) 被错杀**(优质卡位龙头因恐慌/系统性杀跌/短期利空, 基本面未变而价格过度下跌, 预期差)。

| 因子 | 判定标准 | 反例(不满足) |
|------|---------|--------------|
| **① 需求确定** | 下游需求有巨头持续资本开支支撑,极高确定性(AI capex/云厂自研芯片/推理带宽) | 需求靠政策补贴/一次性/概念 |
| **② 供给受限** | "没它不行 + 短期无法复制":技术壁垒高/认证周期长(>1年)/扩产困难(>2年),天然稀缺 | 产能可快速复制/多家可替代/低门槛 |
| **③ 未被充分定价** ★ | **(a) 低关注度**(机构覆盖少/听不懂/定价失真, 紫苏叶) **或 (b) 被错杀**(优质龙头预期差: 基本面未变但价格反映了过度悲观, 如系统性杀跌/短期利空/赛道恐慌) | 价格已充分/过度反映乐观预期(真·泡沫高位); 既无信息差又无预期差 |
| **④ 价值可捕获** | 企业真能从卡脖子地位拿到**定价权 + 锁定客户份额 + 毛利扩张**;利润落到这家口袋 | 需求在但被设备商/客户压价/纯代工/利润落不到自己 |
| **⑤ 存在催化剂** | 短期有明确触发事件(财报释放/关键客户量产/行业指引/认证通过/错杀修复信号),驱动市场认知集中反馈 | 只有长期空间,无近端触发,持有=等死 |

> **关键平衡**:③有两条路径——低关注度紫苏叶(便宜但可能等久,靠催化剂)vs 被错杀龙头(预期差修复,靠基本面未变的确认)。**不再因"高关注度/大市值"直接排除**, 而是问:这个价格**是否充分反映了基本面**? 若被错杀(价 < 价值)就是机会。

## 四、两大理论工具

### 瓶颈理论(Chokepoint Theory)
产业链像木桶,真正限制产能的是**最短那块木板**。大多数投资者只盯 GPU 算力这些显而易见的"长板",真正机会藏在最脆弱、最不可替代的"短板"——卡在关键位置的上游公司(无论大小市值)。

### 紫苏叶理论(路径 a:信息不对称未定价)
AI 大科技公司 = 日料店的"金枪鱼大腹"(食客抢得头破血流);但缺了**紫苏叶**(容器底层微小却关键的部分),整道菜根本做不了。投资中的紫苏叶 = **市值小 + 技术垄断性强 + 对产业链不可或缺**的公司——多数人不知道它存在,但没有它产业链就转不动。

### 错杀龙头(路径 b:预期差未定价,2026-06-15 用户拍板纳入)
**金枪鱼大腹(卡位龙头)在被错杀时也是大机会**。优质龙头因系统性杀跌/短期利空/赛道恐慌被打到 价 < 价值,而其卡位/景气/ROIC 未变 → 预期差买点。判定:① 产业链卡位真实且未恶化 ② 当前估值反映过度悲观(forward PE/PEG/PB 处历史低位或低于可比) ③ 有修复催化剂。**实例:中际旭创 ¥88 错杀买入 → ¥1149**。这类不要求小市值/低关注度, 要求的是**预期差证据 + 卡位未变**。

> **紫苏叶画像**:市值小(机构看不上/覆盖不到)+ 技术垄断(全球 CR3 极高/国产唯一)+ 不可或缺(BOM 占比可能很小但断供整线停)+ 市场不知道(听不懂/归错类)。

## 五、执行 SOP(给 alpha-hunter / chokepoint 分析师)

1. **选主线**:从确定性大主线选 1 条(AI 数据中心/人形机器人/800V 直流供电)
2. **拆产业链**:逐层拆到材料/部件/设备/矿源,标出每层"扩产周期/认证周期/全球玩家数"
3. **定位瓶颈环节**:四维(不可替代/供给集中/产能刚性/价值卡位)找最短木板
4. **推理找紫苏叶**:用碎片信息(专利/客户/产能/矿源)演绎,找该环节市值小+技术垄断+低关注度的标的
5. **五因子打分**:逐只五因子(需求确定/供给受限/低关注度/价值可捕获/催化剂)同时满足才入选
6. **诚实标推理链**:每个推论标"基于什么碎片推出来的",哪些是 verified、哪些是演绎假设(可证伪)

## 六、反偷懒铁律

- **禁止用研报结论替代推理**:研报可作为碎片之一,但不能作为"这是 alpha"的依据(研报覆盖=已知=高关注度)。
- **禁止只因当前利润未兑现就淘汰**:用"价值可捕获+催化剂"判断时机,不是用当前 PE 判生死。
- **核心是"未被充分定价",不是"低关注度"(2026-06-15 用户纠正)**:两条路径——(a) 低关注度紫苏叶(信息不对称) 或 (b) 被错杀的卡位龙头(预期差)。**不再因高关注度/大市值一刀切排除龙头**;对龙头要问"当前价是否充分反映基本面",被错杀(价<价值+卡位未变+有修复催化)就纳入。中际旭创 ¥88 错杀买入是正例。
- **市值必须 verified**:无论紫苏叶还是龙头, 市值/估值数字必须 AKShare 校正(hunter 凭演绎估市值系统性偏小 30-70 倍, 如国瓷估15实际554)。
- **仍要防真泡沫**:排除的不是"高关注度",而是"价格已过度反映乐观预期的真高位"(既无信息差又无预期差)。
