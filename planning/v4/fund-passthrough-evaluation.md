# 基金穿透分析 — 现状评估 + 改进方案

**日期**：2026-06-13
**触发**：用户反馈"持仓里很多是基金,你要穿透分析,现在行业里我都看不到基金,基金本质是股票"

---

## 一、用户持仓真实分布（核实）

```
总持仓 36 项，¥1,053,054
├─ 9 项股票          (~24.4 万, 23%)
├─ 26 项基金/ETF     (~47.1 万, 45%)   ← 主要持仓!
│   ├─ 17 项权益类(沪深300/中证500/纳指100/A500/创业板/半导体芯片/AI/绿电/红利/家电/医疗/新能源车电池/海外互联网...)
│   ├─ 5 项债券基金(稳健收益债/增强回报债/双债添利/国开债/信用债)
│   ├─ 2 项商品基金(黄金ETF/上海金ETF)
│   └─ 2 项 QDII (纳指100/海外中国互联网50)
└─ 1 项现金/活期
```

**关键洞察**：**基金市值 ¥47 万 vs 股票 ¥24 万 = 基金是用户主要持仓方式（66% 权益）**。

不穿透 = 整个组合分析瞎眼一半。

## 二、当前 v4 系统的基金处理能力

### ✅ 已有能力

| 功能 | 实现位置 | 说明 |
|---|---|---|
| 基金分类（按 instrument_type） | `app/services/v4/v4_classifier.py` | 识别 fund/etf 关键词归到 equity/fixed_income/precious_metal/alternative 大类 |
| 大类层处理 | `data/v4/assets/<class>.json` | 把 9 个股+17 权益基金合并算 equity_quota |

### ❌ 缺失能力（**核心 gap**）

| 缺失 | 影响 |
|---|---|
| 基金重仓股穿透 | 不知道易方达 沪深300 ETF 联接 A 实际持有什么股票 |
| 行业暴露聚合 | 行业页只看到 9 个股的行业，看不到 17 权益基金间接贡献的行业 |
| 风格因子分析 | 不知道用户实际暴露在 大盘/小盘/价值/成长/红利 哪个风格 |
| 重叠分析 | 不知道同时持有 沪深300 ETF + 中证 500 + 中证 A500 是不是重复暴露 |
| 整体配比建议 | 因为不穿透，配比层无法给"加配 X 行业 → 应该买什么基金"的具体建议 |

### 实际效果（举例）

用户持有 **¥21698 易方达中证绿色电力 ETF 联接发起式 A**：
- ✅ 当前能识别：fund/equity/electric_power 行业 ETF
- ❌ 不知道：实际持有的是阳光电源(8%)/隆基绿能(7%)/宁德时代(6%)/比亚迪(5%)... 等具体股票
- ❌ 不知道：这个基金间接暴露了 **新能源(45%) + 公用事业(30%) + 储能(15%)** 三个行业
- ❌ 不知道：用户的 ¥21698 实际转换成 ~¥3000 阳光电源 + ~¥2400 隆基 + ~¥1800 宁德时代

## 三、改进方案（按工作量排序）

### Level 1: 基础穿透（必做，10-15 小时）

**目标**：取基金重仓股 + 算行业暴露 + 在行业页展示"间接持仓"

**工作量**：
1. **数据采集** (`scripts/v4_fund_source.py` 新建)
   - 用 AKShare `fund_portfolio_hold_em` 取基金前 10 重仓股
   - 取基金分类(行业/风格/规模) 通过 `fund_individual_basic_info_em`
   - 取基金行业分布 `fund_portfolio_industry_em`
   - 缓存基金穿透数据 `data/v4/_funds/<code>.json`

2. **classifier 升级** (`app/services/v4/v4_classifier.py`)
   - 输出加 `fund_holdings: [{code, name, weight}]` 字段
   - 输出加 `fund_industry_exposure: {半导体: 12%, 新能源: 8%}`
   - 仍保持 instrument_type 大类归类不变

3. **行业聚合** (`app/services/v4/v4_aggregator.py` 新建)
   - 直接持仓 + 基金穿透 = 总行业暴露
   - 输出 `data/v4/inputs/portfolio_aggregated.json`
   - 含: 直接 X% / 间接 Y% / 重叠 Z%

4. **alloc:industry 升级**
   - quota 计算时基于"总行业暴露"非"仅直接股票"
   - stock_weights 表加"间接持仓来自基金 X/Y/Z"

5. **前端展示**
   - 行业页 stocks 表加 "间接持仓" 列（来自基金 X 的间接 ¥3000）
   - 持仓总览页加"基金穿透汇总"卡片

### Level 2: 风格+重叠分析（推荐，6-8 小时）

**目标**：识别风格暴露 + 重复持仓

1. 风格因子拆解：大盘/小盘 + 价值/成长 + 红利 + 海外
2. 重叠分析：同主题多 ETF（沪深300+中证500+A500 都是大盘）
3. 给"基金优化建议"：哪些基金可合并/替换降费

### Level 3: 基金质量评分（长期，10+ 小时）

1. 基金费率扫描（管理+托管费过高警示）
2. 历史业绩 vs 基准
3. 基金经理风格漂移检测
4. 给"基金调仓建议"

## 四、推荐路径

按用户"满血版分析"诉求，**Level 1 必做**（不做整个组合分析瞎眼一半）。

**实施分两批**：

### 批次 1（短期，~6 小时）— 取数+穿透+聚合
- `v4_fund_source.py` 用 AKShare 取重仓股+行业分布
- `v4_classifier.py` 输出加 fund_holdings + fund_industry_exposure
- `v4_aggregator.py` 直接+间接持仓聚合
- 前端行业页加"间接持仓"列

### 批次 2（紧跟，~4 小时）— 整体配比+重叠分析  
- alloc:industry 用聚合后行业暴露算 quota
- 持仓总览页加基金穿透汇总卡
- 重叠预警（同主题 >2 只 ETF）

### 触底约束
- 沙箱无外网，AKShare 拿基金数据需生产环境
- 当前可先**写好 schema + classifier 升级 + aggregator + 前端 UI**，沙箱用 estimated 数据 mock，生产环境跑真实数据
